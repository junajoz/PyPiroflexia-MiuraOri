# tools

Esta carpeta contiene herramientas auxiliares para facilitar la integración del aporte con un repositorio local de PyPiroflexia.

## Archivo incluido

### `install_into_repo.py`

Script auxiliar que copia la carpeta `miura_contrib/` dentro del directorio `python/` de un repositorio PyPiroflexia local.

## Uso

Desde la raíz del aporte:

```bash
python tools/install_into_repo.py /ruta/a/PyPiroflexia-main/python
